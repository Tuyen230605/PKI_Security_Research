# Dàn ý slide 10–12 trang

1. Tên đề tài, nhóm, câu hỏi trung tâm.
2. Bài toán thay thế public key và mục tiêu nghiên cứu.
3. Kiến trúc Root CA → Intermediate CA → server → client.
4. Cấu trúc X.509, SAN, Basic Constraints, EKU.
5. Quy trình path validation và vị trí kiểm tra hostname/trạng thái.
6. Mô hình đe dọa: CA cấp sai, lộ khóa, client kiểm tra thiếu.
7. Thiết kế lab và công cụ.
8. Bảng test cases: điều kiện và kết quả quan sát.
9. Demo trực tiếp 2–3 ca tiêu biểu.
10. Phân tích: chữ ký hợp lệ có thể vẫn FAIL vì yếu tố khác.
11. Giới hạn của lab và hướng mở rộng (CRL/OCSP, CT, ACME).
12. Kết luận và câu hỏi.

Ưu tiên sơ đồ và bảng kết quả rõ ràng; tránh chép nguyên đoạn văn từ báo cáo. File slide thực tế (`.pptx` hoặc nguồn Beamer) sẽ được thêm sau khi kết quả demo đã được kiểm chứng.
